# Benchmark artifacts

- `results.json`: full-precision final serial suite (88 files × 2 strategies,
  seed 0), isolated ablation (3 known-fill hard files × 6 configurations × 3
  seeds) and core-87 dictionary comparison (3 dictionaries × 3 seeds).
- `suite.csv`: complete suite in a convenient tabular format, generated by
  `tools/summarize.py`.
- `exploration/`: explicitly limited evidence from reverted prototypes.
- `local-search.json`: subsequent unshipped experiment, described in report
  Appendix A and reproducible with `tools/local_search_experiment.py`.

`results.json` contains the environment, input/source fingerprints, exact
solver timings, work counts, failure reasons and successful assignment
witnesses. Use `uv run python tools/audit_results.py` to reverify its fills and
check that the measured solver source and dictionaries have not changed.
Successful witnesses are evidence, never inputs to solving.

The principal collector `uv run python tools/measure.py` intentionally records
failure data and exits 0; use `uv run benchmark` for a regression gate that
returns nonzero on any FAIL or INVALID result. The full suite currently fails
that gate on core 87. A timeout must not be relabelled unsatisfiable.

Data provenance: Apple-vendor aarch64 Linux 6.18.15 VM, 5 vCPUs, 7.9 GiB RAM,
CPython 3.14.7; primary dictionary 370,105 surviving words_alpha.txt lines;
5-second budgets; suite seed 0, ablation seeds 0/1/2. Solver timing excludes
loading/indexing and independent verification. The exact dictionary load
and preparation figures, and the alternate dictionary fingerprints, are in
the JSON. See `documentation/README.md` for the report/build protocol.
